## Selected work

### 🧠 MITRE LLM Classifier

A multi-LLM classification pipeline developed as part of research on emerging cyber-threat tactics.

The project uses **Python and LangChain** to orchestrate GPT, Gemini and DeepSeek, processing unstructured OSINT cybersecurity content and mapping model outputs to **MITRE ATT&CK Enterprise tactics**.

My work included:

- multi-LLM orchestration
- prompt design and refinement
- standardized tactic extraction
- model comparison
- accuracy and experimental analysis
- structured processing of cybersecurity text
- reproducible experimental implementation

The implementation supported our scientific paper:

**“An Experimental Evaluation on LLM-Based Classification of Emerging Cyber Threat Tactics” — IEEE SoftCOM 2025**

➡️ [View repository](https://github.com/ArthurWermont/mitre-llm-classifier)

### 🌱 Yby Impacta

A digital platform for **waste traceability, collection management and socio-environmental impact measurement**, developed for real operational use.

I initially contributed as a Software Developer and currently participate in the project's technological evolution as a **Software Development Fellow (BTT6)**.

My work has involved:

- role-based authentication and access control
- client, cooperative and collection-point management
- waste collection tracking
- photographic evidence and operational traceability
- dashboards and ESG indicators
- environmental impact calculations
- report generation and data filtering
- REST API integrations
- PDF and Excel exports
- requirements analysis
- testing and technical documentation
- platform architecture and scalability improvements

Environmental indicators handled by the platform include measurements related to water savings, avoided landfill volume, recyclable material composition and other socio-environmental impacts.

**Stack:** React · TypeScript · Strapi · REST APIs · AWS

> Production platform developed for real operational use. Source code is private.

### 🕸️ Graph-Based Network Infrastructure Analyzer

A Java desktop application for modeling and analyzing network infrastructure using **graph theory**.

The system supports:

- directed and undirected graphs
- weighted and unweighted connections
- adjacency lists and matrices
- BFS and DFS traversal
- graph visualization
- degree and density analysis
- connectivity evaluation
- connected components
- reachability analysis
- cycle detection
- path and cost simulation
- graph-based infrastructure modeling

This project strengthened my understanding of **algorithms, data structures, graph theory and Java application development**.

**Stack:** Java · Graph Theory · Data Structures · Algorithms

➡️ [View repository](https://github.com/ArthurWermont/Graph-Based-Network-Infrastructure-Analyzer)
